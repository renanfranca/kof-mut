## Cause and discriminating reproduction

`SemAssignmentAnalyzer.java:164` checks a simple array element store through `TypeChecker.isAssignable`. The local history identifies introduction of this gate in `86d440ca72175776bcda6992beabd284a1d75a73`. `TypeChecker.java:173` handles array-to-array assignment; its analyzer-aware reference path at line 451 requires two ClassType values before reaching the Object root case. It does not cover ArrayType→Object. This source finding explains the observed rejection; it does not claim the two compiler distributions differ only in this gate.

The synthetic Kof programs in `E/corrected-probes/<version>-<variant>/Main.kf` construct a String array, locate `Receiver.main(String[])` by reflection, create one Object slot and either store `arguments` directly or store `arguments as Object`. The receiver asserts four exact values: empty, spaced, Unicode and newline. Compilation and JVM execution are separate subprocesses:

```bash
"<distribution>/bin/kof" build "<probe>/Main.kf" --target jvm --output "<probe>/classes"
"<distribution>/jdk/bin/java" -cp "<probe>/classes:<distribution>/lib/kof.jar" Default.Main
```

| Distribution / store | Build native exit | Reflection native exit | Observed evidence |
| --- | --- | --- | --- |
| 0.6.6 / direct | 0 | 0 | One String[] received, all four values exact |
| 0.6.6 / explicit Object | 0 | 0 | Same receiver assertions pass |
| 0.6.8 / direct | 1 | Not attempted | `SEM021`: cannot assign String[] to array element of Object |
| 0.6.8 / explicit Object | 0 | 0 | Same receiver assertions pass |

`corrected-probes/probes.json` and individual stdout/stderr files retain every command and result. The initial harness incorrectly looked for `Default.Receiver` while Kof emitted `Receiver.class`; its three ClassNotFoundException executions are retained in E, along with their builds. The corrected harness uses the observed class name. Those initial harness failures are not product evidence or accepted reflection proofs.

Unchanged public source invocation `./bin/kof-mut --version` returns 0 with 0.6.6 and `KofMut 0.1.0`, but returns 2 with 0.6.8 and `SEM021` at `Compatibility.kf:360`. Both complete streams are retained as `<version>-base-version.*`. After the two production conversions, 0.6.8 `--version` passes, native exit 0, 25.096 external seconds (`fixed-068-version.*`).
